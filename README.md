# Vitae recruiting skills

Public recruiting playbooks for recruiters and AI assistants, with optional [Vitae.ai](https://vitae.ai) integration.

This repository is an initial scaffold. No installable skills have been released yet.

## Initial catalog

- Job intake
- Hiring scorecard
- Sourcing strategy
- Candidate screening
- Candidate outreach
- Interview invitation
- Interview kit
- Candidate presentation
- Recruitment workflow coordination

Later additions can cover offers, rejection communication, placement handover, talent-pool nurturing, client updates, and agency business development.

## Layout

Each installable skill will have a top-level directory containing `SKILL.md`, a reader-facing `README.md`, and optional `references/`, `assets/`, and `examples/` directories. Keep the catalog consistent with the [Agent Skills specification](https://agentskills.io/specification).

See [the authoring guide](docs/authoring.md) for the required workflow contract.

Connection packaging belongs in [vitaedotai/agent](https://github.com/vitaedotai/agent).

Use fictional examples. Keep candidate data, client information, credentials, and internal engineering workflows out of this repository.
